    Retrieval-augmented generation

    Multi-Document RAG Agent

    Ask questions across a folder of PDFs, Word files and PowerPoint decks. It loads each format, splits the text into chunks, embeds them with MiniLM, stores them in Chroma and answers from the passages it retrieves. I built several versions, from a CLI tool to a multimodal one that also reads images.
